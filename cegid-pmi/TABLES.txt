 NOTES SUR LA STRUCTURE
================================================================================

PFACCLI / PFACFOU — Journal comptable des factures
---------------------------------------------------
Ces tables ne contiennent PAS de lignes article. Chaque facture génère exactement
3 écritures comptables, identifiées par PFCTCARTE :

  PFKTFACTUR  = numéro de facture (clé)
  PFKNIND     = numéro d'ordre de l'écriture (1, 2, 3)
  PFCTCARTE   = type d'écriture :
                  A = ligne client/fournisseur TTC  (débit, PFCTSENS=D)
                  B = ligne TVA collectée/déductible (crédit, PFCTSENS=C)
                  C = ligne produit HT / charge HT  (crédit, PFCTSENS=C)
  PFITCPT     = numéro de compte comptable (411x client, 401x fourn., 4457x TVA, 7xxx produit, 6xxx charge)
  PFCNMHT     = montant HT (renseigné uniquement sur la ligne A)
  PFCNMTVA    = montant TVA (renseigné uniquement sur la ligne A)
  PFCNMT      = montant de l'écriture

Les lignes article commerciales des factures clients sont dans LEXPCLI (expéditions)
ou LCOMCLI (commandes). Il n'existe pas de table LFACCLI / LFACFOU.
